# Manrope

Локальная веб-версия Manrope с кириллицей и переменным весом 200–800.
Источник: [Manrope в официальном репозитории Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), файл `Manrope[wght].ttf`.
[Страница семейства в Google Fonts](https://fonts.google.com/specimen/Manrope).

Файл сжат в WOFF2 с помощью FontTools; рисунок и полный набор символов сохранены.
