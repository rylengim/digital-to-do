# Ubuntu Sans

Локальная веб-версия Ubuntu Sans с кириллицей и переменным весом 100–800.
Источник: `UbuntuSans[wdth,wght].ttf` из системного пакета `fonts-ubuntu`.
Страница семейства: https://design.ubuntu.com/font/.

Файл сжат в WOFF2 с помощью FontTools; рисунок и набор символов не изменены.
Согласно Ubuntu Font Licence 1.0 внутреннее имя производной версии —
`Ubuntu Sans derivative Web`. Copyright и полный текст лицензии — в `LICENSE.txt`.
FontTools не нужен для установки, запуска или сборки приложения.
