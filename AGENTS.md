# Правила проекта

- Это отдельное тестовое задание The Digital: простой To-Do List. Общаться с пользователем по-русски.
- Начинать с `TASK.md` и `README.md`. Соблюдать обязательный объём; расширения не являются критерием готовности.
- Выбранный пользователем стек — TypeScript, Vite, обычный CSS и `localStorage`. Предпочитать простую реализацию; сервер и UI-фреймворк для текущего объёма не нужны.
- План — `tasks/plan.md`, текущие шаги — `tasks/todo.md`. Основной агент реализует и исправляет; независимый проверяющий проверяет требования, код и поведение. Не редактировать одни файлы одновременно.
- Проверять реальные сценарии добавления, выполнения, удаления и перезагрузки. Для браузерной реализации использовать проверку в браузере; не выдавать только статическое чтение кода за работающий продукт.
- В README честно указывать использованные AI-инструменты, их роль и выполненные проверки. Само тестовое прямо просит раскрыть инструменты; не придумывать ручное авторство или несуществующие тесты.
- Не помещать в проект резюме, контакты рекрутера, переписку о найме, личные обстоятельства пользователя или материалы других проектов.
- Работать только на текущем устройстве. Не обращаться к другим хостам и общим подключениям аккаунта ради личных данных. Не использовать Obsidian или синхронизируемые папки для частных результатов.
- Локальная подготовка не означает разрешение публиковать репозиторий, выкладывать сайт или отправлять результат работодателю. Для этих действий нужно отдельное указание пользователя.
- Не удалять локальные или удалённые Git-ветки автоматически. Минимальный срок хранения после слияния либо подтверждённого завершения — семь полных суток; истечение срока само по себе не является командой удалить ветку.
