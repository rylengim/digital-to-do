# Тестовое задание: To-Do List

Источник: текст задания, переданный пользователем 2026-11-08. Дата самого сообщения работодателя и начало отсчёта срока не указаны.

## Точный текст работодателя

Тогда следующий этап небольшое тестовое задание.

Задача: Создать простой веб-сайт «Список задач» (To-Do List) с помощью любого AI-инструмента (ChatGPT, Cursor, Claude Code и т. д.).

Функционал:
1. Добавление новых задач.
2. Отметка выполненных задач.
3. Удаление задач.
4. Сохранение задач после обновления страницы.

Дизайн на ваше усмотрение, главное, чтобы всё выглядело аккуратно и работало корректно.

Результат: Пришлите ссылку на GitHub с кодом проекта и коротко расскажите, какие AI-инструменты использовали. Если скинете также ссылку на рабочий сайт - будет преимуществом.

Время выполнения: 2 рабочих дня.

## Критерии приёмки

Уточнение пользователя от 2026-11-08: работодатель оставил выбор стека на усмотрение кандидата; разрешено использовать open-source библиотеки. Пользователь выбрал TypeScript + Vite + CSS + `localStorage`. Это решение кандидата, а не требование работодателя.

Обязательные функции:

- [ ] Введённая задача добавляется в список.
- [ ] Задачу можно отметить выполненной; состояние визуально различимо.
- [ ] Задачу можно удалить; удаление не меняет остальные задачи.
- [ ] После обновления страницы задачи и состояния выполнения сохраняются, удалённые задачи не появляются заново.

Обязательные материалы сдачи:

- [ ] Аккуратный интерфейс с читаемым текстом, понятными элементами управления и последовательными отступами.
- [ ] Ссылка на GitHub с кодом и краткое описание фактически использованных AI-инструментов.

Рабочий сайт — необязательное преимущество, не обязательное условие задания.

Разумные технические проверки, добавленные для качества, а не заявленные работодателем:

- [ ] Пустая строка или одни пробелы не создают задачу.
- [ ] Пользовательский текст отображается как текст, а не исполняемый HTML.
- [ ] Основные действия доступны с клавиатуры; виден фокус, у контролов понятные подписи.
- [ ] На узком экране нет горизонтальной прокрутки и недоступных кнопок.
- [ ] Проект запускается по README; основные сценарии не вызывают ошибок в консоли.
